# Little Muffin | 綴歌・瑪芬

全年齡戀愛視覺小說（Galgame）。女主角是性轉版的跩哥・馬份「**綴歌・瑪芬**」。

玩家扮演哈利，舞台是《哈利波特：混血王子的背叛》的 IF 世界線。

**本作為非官方同人作品，與《哈利波特》原作者及版權方無關，僅供免費、非商業交流。**

## 遊戲內容

- 序章～終章共 12 章，約 11 萬字。第一輪約 4～5 小時，看完全部結局約 7 小時。
- 五個結局：真結局、苦甜結局、原著結局、壞結局、搞笑結局。選項、好感度（心動）、信任與良知會決定走向。
- 章末的「心鎖」顯示她對你的信任；每章一頁她視角的「鎖心日記」。
- 「妙麗的小辭典」：哈利波特名詞第一次出現時點一下就有白話說明，沒看過原著也能玩。
- 特典：CG 鑑賞（含回想）、結局一覽、章節選擇、鎖心日記；真結局通關後解鎖特別篇與後日談（泳裝回）。

## 網頁版

- 用電腦或手機的瀏覽器打開 **https://little-muffin.app/** 就能玩，內容和桌面版相同。手機請轉成橫向。
- 存檔存在這個瀏覽器裡。清除瀏覽器資料、換瀏覽器或換裝置時存檔不會跟著走，請用「設定 → 存檔 → 匯出存檔」備份成 .zip。
- 匯出的 .zip 可以在其他裝置的網頁版或桌面版用「匯入存檔」讀進去，兩邊的存檔互通。
- 想在不同裝置之間接著玩，也可以在設定裡綁定 Google 帳號，把存檔備份到雲端（選用，不綁定也能玩）。個人資料的處理見網站上的隱私權聲明。
- 網頁版不保證一直開放；關閉前會在網站上公告，請記得先匯出存檔，桌面版還是能接著玩。

## 桌面版

1. 到右邊的 [**Releases**](https://github.com/k22949706/LittleMuffin/releases) 下載最新版的 zip（約 240 MB，含音樂與音效）。
2. 解壓縮到任意資料夾。路徑裡有中文也沒關係。
3. 打開解壓出來的 `LittleMuffin` 資料夾，雙擊 **`LittleMuffin.exe`** 開始遊戲。

不需要安裝任何東西。Windows 第一次執行時如果跳出「Windows 已保護您的電腦」，按「其他資訊 → 仍要執行」。

## 存檔

- 存檔、解鎖的 CG 和結局紀錄都存在電腦的使用者資料夾 `%APPDATA%\RenPy\mafen-1791521068`，**不在遊戲資料夾裡**。把這串路徑貼到檔案總管的網址列就能打開。
- 更新到新版本時，可以直接**刪掉舊版的 `LittleMuffin` 資料夾**，再解壓縮新版執行，存檔和解鎖紀錄都會保留。
- 想從頭開始的話，刪掉上面那個存檔資料夾。
- 「設定 → 存檔」可以把存檔和遊玩紀錄匯出成一個 .zip，在網頁版或其他電腦匯入。

全年齢向けの恋愛ビジュアルノベル（ギャルゲー）です。ヒロインは、ドラコ・マルフォイの性別を反転させた女の子「**ドラコニア・マフィン**」。

## ゲーム内容

- 序章〜終章の全12章、日本語版で約17万字。1周目は4〜5時間ほど、すべてのエンディングを見るまで約7時間です。
- エンディングは5種類：トゥルーエンド、ほろ苦エンド、原作エンド、バッドエンド、ジョークエンド。選択肢と、好感度（ときめき）・信頼・良心のパラメータで行き先が変わります。
- 章の終わりに出てくる「心の錠前」は、彼女があなたをどれだけ信頼しているかのしるし。各章に1ページずつ、彼女の視点で書かれた「錠前日記」もあります。
- 「ハーマイオニーのミニ辞典」：『ハリー・ポッター』の用語が初めて出てきたときにクリックすると、やさしい解説が読めます。原作を知らなくても楽しめます。
- おまけ：CG鑑賞（回想つき）、エンディング一覧、チャプター選択、錠前日記。トゥルーエンドをクリアすると、特別編と後日談（水着回）が解放されます。

## ブラウザ版

- PC やスマートフォンのブラウザで **https://little-muffin.app/ja/** を開くと、そのまま遊べます。内容はデスクトップ版と同じです。スマートフォンは横向きにしてください。
- セーブデータはそのブラウザの中に保存されます。ブラウザのデータを消したり、ブラウザや端末を変えたりすると引き継がれないので、「設定 → セーブデータ → エクスポート」で .zip にバックアップしてください。
- 書き出した .zip は、ほかの端末のブラウザ版やデスクトップ版で「インポート」から読み込めます。セーブデータは両方で共通です。
- 別の端末で続きを遊びたい場合は、設定で Google アカウントと連携して、セーブデータをクラウドにバックアップすることもできます（任意です。連携しなくても遊べます）。個人情報の取り扱いはサイトのプライバシーポリシーをご覧ください。
- ブラウザ版の公開を続けることは保証していません。終了する前にサイトでお知らせしますので、セーブデータを書き出しておいてください。デスクトップ版で続きを遊べます。

## PC版

1. 右側の [**Releases**](https://github.com/k22949706/LittleMuffin/releases) から最新版のzipをダウンロードします（約 240 MB、BGM・効果音を含みます）。
2. 好きなフォルダに展開します。フォルダのパスに日本語が入っていても大丈夫です。
3. 展開してできた `LittleMuffin` フォルダを開き、**`LittleMuffin.exe`** をダブルクリックするとゲームが始まります。

インストール作業は必要ありません。初回起動時に「Windows によって PC が保護されました」と表示された場合は、「詳細情報 → 実行」を押してください。

## セーブデータ

- セーブデータ、解放した CG やエンディングの記録は、ゲームのフォルダではなく、PC のユーザーフォルダ `%APPDATA%\RenPy\mafen-1791521068` に保存されます。このパスをエクスプローラーのアドレスバーに貼り付けると開けます。
- 新しいバージョンに更新するときは、**古い `LittleMuffin` フォルダを削除**してから新しいバージョンを展開して起動しても、セーブデータと記録はそのまま引き継がれます。
- 最初からやり直したい場合は、上記のセーブデータのフォルダを削除してください。
- 「設定 → セーブデータ」の「エクスポート」で、セーブデータと記録を1つの .zip にまとめて、ブラウザ版やほかの PC で読み込めます。
